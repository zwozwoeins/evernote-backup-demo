Schritt 1: Notizbuch aus Evernote speichern

Öffnen Sie Evernote am Mac, klicken Sie mit der rechten Maustaste auf ein Notizbuch und wählen Sie „Notizbuch exportieren …“.

Genauer zeigen
  1. Das Programm Evernote am Mac öffnen (nicht die Internetseite – dort geht es nicht).
  2. Links auf Notizbücher klicken.
  3. Rechte Maustaste (oder ctrl + Klick) auf ein Notizbuch → Notizbuch exportieren …
  4. Bei „Format“ ENEX wählen und auf Exportieren klicken.
  5. Beim ersten Mal auf dem Schreibtisch einen neuen Ordner „Evernote-Sicherung“ anlegen und dort speichern – alle weiteren Notizbücher auch dorthin.
  6. Für jedes Notizbuch wiederholen.

Schritt 2: Dateien prüfen lassen

Ziehen Sie die gespeicherten Dateien in das gelbe Feld – oder drücken Sie den großen Knopf.

Schritt 3: In Notizen holen

Öffnen Sie Notizen am Mac, klicken Sie links auf iCloud und wählen Sie oben Datei → In „Notizen“ importieren …

Genauer zeigen
  1. Programm Notizen öffnen (gelbes Notizblock-Symbol).
  2. Links unter iCloud einen Ordner anklicken – nur so erscheinen die Notizen später auch auf iPhone und iPad.
  3. Oben im Menü Datei → In „Notizen“ importieren …
  4. Einfach den ganzen Ordner „Evernote-Sicherung“ vom Schreibtisch anklicken → Importieren → noch einmal Importieren. So kommen alle Notizbücher auf einmal.

Tipp: Vorher den Mac auf den neuesten Stand bringen (Apfel-Menü → Systemeinstellungen → Allgemein → Softwareupdate). Sonst fehlen manchmal Bilder und Dateien.

Schritt 4: Nachsehen – fertig!

In Notizen gibt es jetzt den Ordner „Importierte Notizen“. Nach kurzer Zeit erscheint er auch auf iPhone und iPad.

  • Bei vielen Notizen kann es einige Stunden dauern, bis alles auf iPhone und iPad ist. Internet anlassen.
  • Den Ordner „Evernote-Sicherung“ aufheben (z. B. auf einen USB-Stick) – das ist Ihre zusätzliche Sicherung.
  • Evernote erst löschen, wenn alles in Notizen zu sehen ist.

VORSCHAU – nur zum Ansehen. Hier passiert noch nichts Echtes.
